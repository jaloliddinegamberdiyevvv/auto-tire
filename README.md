# 🚗 AutoTire — Tire Shop Management System

**AutoTire** is a modern and responsive web application designed to simplify and manage daily operations of tire shops. It provides a centralized platform for managing inventory, sales, profits, debts, and financial records through a clean and intuitive interface.

## 📌 About the Project

AutoTire was developed to help tire shop owners manage their business operations more efficiently, reduce manual calculations, and keep important business information organized in one place.

The application focuses on inventory management, sales tracking, and financial control, providing a convenient dashboard for monitoring the overall business situation.

## ✨ Features

- **Dashboard** — Overview of important business statistics and activities.
- **Inventory Management** — Manage products across different categories.
- **Product Categories** — Separate management for:
  - Passenger Car Tires
  - Truck Tires
  - Rims
  - Batteries
- **Sales Management** — Track and manage product sales.
- **Profit Tracking** — Monitor total profit and sales performance.
- **Debt Management** — Keep track of customer debts.
- **Financial Overview** — View important financial information in one place.
- **Search Functionality** — Quickly find products and sales records.
- **Responsive Design** — Adapted for desktop, tablet, and mobile screens.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/jaloliddinegamberdiyevvv/auto-tire.git
   ```

2. Navigate to the project directory:

   ```bash
   cd auto-tire
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run -d chrome
   ```
